# Vértice Tecnologia

Site institucional em português para uma empresa fictícia de infraestrutura de TI, inspirado no segmento dos sites InfraNet e FiberSys. Identidade visual, textos e código próprios.

## Executar

O site está em `dist/`. Abra `dist/index.html` ou sirva essa pasta com um servidor HTTP. Não há dependências, instalação ou compilação. Para hospedar no GitHub Pages, Netlify ou outro serviço estático, publique o conteúdo de `dist/`.

## Funcionalidades

- Layout adaptado para computador, tablet e celular.
- Menu móvel, navegação por âncoras e detalhes acessíveis dos quatro serviços.
- Abas de exemplos de aplicação com suporte ao teclado.
- Perguntas frequentes e informações de privacidade.
- Formulário validado que gera um resumo, permite copiar e baixar em TXT.

O formulário é demonstrativo: não envia mensagens nem grava dados em servidor ou no armazenamento local. A empresa é fictícia; não foram incluídos telefones, endereços, clientes ou depoimentos inventados. Para receber contatos reais, é necessário conectar um destino de atendimento e atualizar os textos do formulário.

## Personalizar

- Conteúdo, navegação e formulário: `dist/index.html`.
- Paleta, tipografia e layout: `dist/styles.css`.
- Serviços detalhados, abas e interações: `dist/app.js`.
- Imagem principal e fonte: `dist/assets/`.
